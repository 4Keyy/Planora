# Реестр дефектов интерфейса Planora

БЛОК 18.2 аудита. Отсортировано по «влияние × частота ÷ стоимость исправления».

- Дата: 2026-09-13
- Замеры: продакшен-сборка (`next build` + `next start`), Chromium 1228, матрица 360–2560 px
- Инструменты: `docs/ui-audit/tools/{static,contrast,live}-scan.mjs`, фикстуры `mock-api.mjs`
- Достоверность: `[измерено]` в браузере, `[вычислено]` скриптом, `[из кода]`, `[гипотеза]`

**Серьёзность:** `блокер` — часть пользователей не может выполнить задачу; `высокая` — видит
каждый каждый день либо провал критерия WCAG уровня A/AA; `средняя` — заметное неудобство;
`низкая` — мешает развитию; `косметика`.
