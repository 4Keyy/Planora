# Целевое состояние интерфейса Planora

БЛОК 17 аудита. Каждое требование — правило, число и способ автоматической проверки.
Формулировки подобраны так, чтобы превращаться в тест или линт-правило без доработки.

Базовая линия снята 2026-09-13 скриптами `docs/ui-audit/tools/`. После исправлений те же
скрипты прогоняются повторно и сравниваются с колонкой «сейчас».

## Неприкосновенное

Ни одно правило выше не должно нарушить:

| Что | Источник | Почему |
|---|---|---|
