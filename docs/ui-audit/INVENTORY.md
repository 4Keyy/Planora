### Что из этого следует

**Пустые состояния реализованы везде, где есть список.** `[из кода]` Это опровергает исходное
подозрение аудита: ни один список не остаётся без пустого состояния. Маршруты без пустого
состояния — это маршруты без списка (`/`, `/auth/*`, `/branch/[id]`), то есть «неприменимо»,
а не «пропущено».

**Обработка ошибки загрузки рассогласована.** `[из кода]` Три маршрута (`/tasks`, `/categories`,
`/profile`) проглатывают отказ запроса в тост, который исчезает, — после чего экран выглядит
просто пустым, неотличимо от «данных нет». Сегментные `error.tsx` у них есть, но ловят только
исключения рендера, а не отказ загрузки.

**Ни один из 12 маршрутов не задаёт собственный `<title>`.** `[измерено]` Все наследуют
единственный заголовок из `frontend/src/app/layout.tsx:19` — «Planora | Private Shared Tasks».
Проверено в браузере на всех шести публичных маршрутах: заголовок вкладки совпадает посимвольно.

**Состояний «нет прав» и «офлайн» не существует нигде.** `[из кода]` 401 обрабатывается
централизованно (`lib/api.ts:261`–`:300`), 403 повторяется один раз ради CSRF и дальше молча
пробрасывается (`:313`–`:331`), сетевые отказы только логируются (`:332`–`:343`). Единственное
место, где 403 виден пользователю, — `/branch/[id]`, где он слит с 404 и сетевым отказом в одну
формулировку.

**Пять маршрутов дублируют работу `AuthGuard`** собственным `useEffect`-редиректом
(`dashboard/page.tsx:313`, `tasks/page.tsx:310`, `completed/page.tsx:214`,
`categories/page.tsx:612`, `profile/page.tsx:490`); `/branch/[id]` — единственный, кто полагается
только на гейт. `[из кода]`

### Порядок наложения, фактический

По возрастанию `[из кода]`: `-10` фон (`color-bends-layer.tsx:92`) → `0…50` локальные подъёмы →
`120/121` Radix Dialog (не смонтирован) → `1000` навбар (`navbar.tsx:178`) → `1100` колокольчик →
**`1500` тост** → `2000/2001` все четыре самодельные модалки → `3000` портальный поповер →
`5000` `icon-picker` (не смонтирован).

Два следствия, оба проверяемые:

1. **Тост всегда ниже любой модалки.** 1500 < 2000. Любое сообщение об успехе или ошибке,
   выпущенное при открытой модалке, визуально скрыто за ней.
2. **Портальный поповер (3000) выше любой модалки.** Он портируется прямо в `document.body`
   и не заключён в контекст наложения модалки; открытый селектор из `create-todo-panel.tsx:635`,
   `:664`, `:698` окажется поверх открывшейся модалки.

Из восьми объявленных ярусов иерархии (`design-tokens.ts:150`–`:159`) в продукте используется
**один** — `toast`, через утилиту `z-toast` в `ui/toast.tsx:77`. Для `dropdown`, `sticky`,
`overlay`, `modal`, `popover`, `tooltip`, `base` нет ни одного применения. `[вычислено]`

Компонента тултипа не существует; в зависимости не подключён `@radix-ui/react-tooltip`, а роль
подсказок исполняют нативные атрибуты `title=`. `[из кода]`
