Не выполнялись: измерение Core Web Vitals (Lighthouse), кроссбраузерные и мобильные прогоны,
автоматическая проверка доступности (axe), Playwright E2E (нужен Docker-стек), покадровые пробы

рантайме здесь основаны на коде и результатах прошлых проходов (`docs/testing.md`), а не на новых
измерениях. Крупнейшие компоненты (`branch-feed.tsx`, `profile/page.tsx`) разобраны по ключевым
путям данных и эффектов, а не построчно; их построчное покрытие — в реестрах `inventory.md`.

## Главные риски

1. **FE-01** — на `/tasks` пропадают задачи сверх сотни (размер страницы 200 против серверного
   максимума 100).
2. **FE-02** — после загрузки аватара не сохраняется профиль (валидатор отклоняет собственный путь
   аватара).
3. **FE-12** — параллельный refresh из нескольких вкладок может сработать как защита от кражи
   токена и разлогинить пользователя на всех устройствах.
4. **FE-27** — 1881 юнит-тест выполняется на React 18, а пользователи работают на встроенном в
   Next React 19.
5. **FE-30** — E2E-сценарии не запускаются автоматически при принятом процессе прямых коммитов в
   `main`.
