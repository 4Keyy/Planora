# План исправлений фронтенда — 2026-10-20

План опирается на [реестр находок](findings.md) (`FE-*`). Принцип: **внутреннее качество растёт,
пользовательский опыт остаётся прежним**. Видимы только исправления дефектов. Каждая задача —
отдельный коммит или небольшая серия коммитов в `main` с тестом, обновлённой документацией и
записью в `CHANGELOG.md`.

## Правила выполнения для каждой задачи

1. До изменения — тест, воспроизводящий дефект (RED), или эталон поведения, если это рефакторинг.
2. Изменение минимальное: без новых зависимостей, без смены разметки, классов, длительностей и
   кривых анимаций, если задача прямо этого не требует.
3. Проверки перед коммитом: `npm run lint`, `npm run type-check`, `npm run test:coverage` (пороги
   85% не падают), `npm run build`; для задач с бэкендом — `dotnet build` и затронутые xUnit-тесты;
   для задач, меняющих поведение, — Playwright-сценарий фазы 0.
4. Визуальное сравнение с эталонами фазы 0: отличий нет, кроме заранее объявленного исправления.
5. Документация по карте `doc-sync` (API, features, testing, configuration, auth-security).

## Критерии завершения плана

План выполнен, когда закрыты все P0–P2 из сводной таблицы реестра, выполнены
[эталонные критерии](target-state.md) и все проверки фазы 0 зелёные на итоговом `main`.
