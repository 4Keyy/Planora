actor exclusion, специальное quoted-author уведомление и JSON payload сохранены.

Восемь provider-тестов проверяют отказ последнего recipient, отказ INSERT,
отмену, update/delete rollback, unexpected profile dependency и success matrix

из отдельного контекста. Profile fault инъецирован через интерфейс; штатный
