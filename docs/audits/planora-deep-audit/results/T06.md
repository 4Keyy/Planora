# T06 — Realtime authorization lifetime

Status: **DIST-004 implemented; live cloud acceptance pending**. Other T06 findings
are outside this change. This report does not certify the whole Realtime service.

## Behavior

- Task-room delivery resolves the current Todo audience and uses per-user groups,
  preserving SignalR Redis backplane routing without a new shared registry.
- Join and typing check JWT expiry/security stamp before and after authorization.
  Authoritative access denial evicts the caller; an RPC outage suppresses the event
  without erasing a legitimate membership. Leave/disconnect cannot signal a room
  the caller never joined or no longer has permission to address.
- A node-local hosted monitor checks registered idle sessions every 15 seconds.
  Expiry, stamp revocation and Redis lookup failure abort the socket and remove
  its registration and memberships. Scheduling/Redis latency adds to the interval.
  Group-cleanup failure cannot keep the socket alive. Native authentication-expiry
  closure is enabled as well.
- A silent member revoked from a task can physically remain in a per-user group
  until invocation/disconnect, but fresh audience selection no longer addresses it.
  An event whose actor has already lost access, or whose task was deleted, is
  suppressed if the audience cannot be established. Notification/feed cleanup
  paths and event payloads retain their existing contracts.

## Verification

The original five audience/typing regressions and three idle-session regressions
failed before their corresponding fixes. Final targeted result: **86 passed,
14 skipped, 0 failed**, with .NET SDK 10.0.300 and one build/test worker. The skips
are existing PostgreSQL facts without a provider environment in that targeted run.

Tests cover live audience changes, normal delivery, expiry before/during RPC,
stamp rotation, Redis outage, monitor tick, cancellation, cleanup failure and DI
singleton/hosted identity. Independent review found the initial passive stamp gap;
the monitor closes it and the second review found no new blocker in this scope.

Live WebSocket expiry/revocation, Redis fault injection and two-node backplane
delivery remain acceptance gates before exposing cloud application routes.
